Mirada

Las puertas y las llaves crecen cuando las miras.
Lo que te persigue crece cuando le das la espalda.

WASD para moverte, ratón para mirar, Shift para correr, C para agacharte, E o clic para lanzar una piedra, F para fijar la mirada, Espacio para parpadear (desde la sala 3), H para ayuda, Esc para pausar.
El fantasma azul repite tu mejor carrera en cada sala.
Las barras de abajo tienen su nombre.
Si el ratón no gira, arrastra con el botón pulsado o usa las flechas.
